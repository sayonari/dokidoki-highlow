# ドキドキFX 〜爆益チャレンジ〜

**▶ 遊ぶ：https://sayonari.github.io/dokidoki-fx/**

ブラウザで遊べる FX（外国為替）体験ゲームです．所持金 10 万円（ゲーム内のおもちゃのお金）で，ドル円が「上がる／下がる」をボタン連打で予想し，数秒後に自動で決済されます．連勝で派手な演出，5 連勝で大当たり！

> ⚠️ これはゲームです．本物のお金は動きません．投資の助言や勧誘ではありません．

## 相場モード
| モード | 内容 |
|---|---|
| 🔴 リアル（ライブ） | 本物のドル円レートをリアルタイムで（平日のみ．あなたのブラウザから GMOコイン外国為替FX の公開 API に直接接続） |
| 📈 リアルっぽい | 本物そっくりの作り物の相場．売値と買値の差（スプレッド）の分だけ期待値はマイナス |
| 🎲 完全ランダム | コイン投げ．手数料ゼロで期待値ぴったり 0 |
| 😈 負け越しがち／💀 必ず負け越し | 胴元が値動きを操作するとどうなるか |
| 😇 勝ち越しがち／👑 必ず勝ち越し | 現実には存在しない夢のモード |
| 🎁 ヒミツ | どのモードかは終わってからのお楽しみ（予想もできます） |

レバレッジは 1〜1000 倍（日本の個人向け FX の上限は 25 倍）．ロスカットやゼロカットも体験できます．結果画面では，今回払ったコストや「25 倍だったらいくらだったか」などを振り返れます．

「必ず負け越し／必ず勝ち越し」は，決済のたびに勝敗と累積損益の条件を確かめて値動きを最小限に調整する仕組みで，どんな押し方をしても必ずそうなります（6 種類の自動プレイヤー × 1,000 ラウンドのシミュレーションで検証：`npx tsx scripts/simulate.ts 1000`）．

## 開発
```bash
npm ci
npm run dev        # 開発サーバ
npx vite build     # dist/index.html（1ファイル）を生成
```
Vite + TypeScript（フレームワークなし）．効果音・BGM はすべて Web Audio でその場で合成しています．

## データについて
- ライブモードのレートは [GMOコイン 外国為替FX Public API](https://api.coin.z.com/fxdocs/) から，遊ぶ人のブラウザが直接取得します．
- 開発者の手元版には過去の実データを再生するモードがありますが，データの利用条件のため公開版には含めていません．
